Design Notes

Interest Chips
Pill-shaped chips with emoji prefixes. On select: violet glow border + subtle background fill. On hover: border highlights. Chips wrap naturally in a flex container for responsive sizing.
Portal Cards
Photos kept with cosmic gradient overlay (transparent → deep navy). On select: violet glow border intensifies, checkmark badge scales in with spring animation. Cards lift on hover (translateY). "or" badge floats between cards.
Card Transitions
After selection, current cards exit with opacity + translateX. New cards enter from opposite side with staggered timing. 500ms auto-advance preserved. Framer Motion AnimatePresence for smooth mounting/unmounting.
RIASEC Bars
Each bar has a unique color that animates width on mount (staggered by 100ms). Sorted by score descending. Gradient fill adds depth. Percentage labels right-aligned for easy scanning.
Progress Bar
Thin gradient bar with subtle glow. Violet-to-indigo fill. Animates width smoothly on each question. Question count shown as "7 of 20" — compact and clear.
Summary Tags
Top values get an amber "highlight" treatment to show what stood out most. Regular tags use subtle violet. All use pill shape for consistency with the interests page chips.
